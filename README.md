# Корпус редуктора вала Kusters (00.000СБ) — 3D-модель для КОМПАС-3D v24

Скрипт строит деталь `.m3d` по сборочному чертежу через COM API КОМПАС.

## Запуск (Windows, PowerShell)

```powershell
cd путь\к\папке
powershell -ExecutionPolicy Bypass -File .\run_kompas.ps1
# или с указанием файла:
powershell -ExecutionPolicy Bypass -File .\run_kompas.ps1 -Output "D:\models\korpus.m3d"
```

`run_kompas.ps1` создаёт `.venv`, ставит `pywin32`, проверяет регистрацию COM-сервера
КОМПАС (при необходимости выполняет `kOMPAS.exe /regserver` с правами администратора)
и запускает `build_korpus.py`. Если КОМПАС установлен не в
`C:\Program Files\ASCON\KOMPAS-3D v24`, укажите `-KompasDir`.

Проверка геометрии без КОМПАС: `python build_korpus.py --dry-run`.

## Что строится

Передняя стенка 28 мм (контур Ø905 + касательные к нижней части, габарит 1100,
межосевое 495), обечайка Ø905/Ø830 длиной до 250, нижняя часть с вылетом 117 и
стенками 10, прилив нижнего вала до 55; расточки Ø465H9, Ø665H11×6, Ø860H9×25,
Ø260H9, Ø140; отверстия 12×M12 на Ø640, 8×Ø18 на Ø500, 6×Ø49 на Ø720,
8×M16 на Ø320, 20×M10 на Ø880 (резьбовые — под сверло, без косметической резьбы).

Упрощено: площадка «Ф» с 5×M16, радиальные отверстия Ø69/G2, сливные G1/2 и G2,
фаски C5 и 3×45°.
